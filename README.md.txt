# Fake News Detection using Machine Learning

## Project Description
This project focuses on detecting fake news using machine learning techniques.
Text-based news articles are classified as fake or real using TF-IDF feature
extraction and the Naive Bayes algorithm.

## Objectives
- Detect fake news automatically
- Preprocess and clean text data
- Apply TF-IDF for feature extraction
- Use Naive Bayes for classification
- Evaluate performance using accuracy

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn

## Dataset
- CSV file containing news text and labels
- Label 0: Fake News
- Label 1: Real News

## Methodology
1. Data preprocessing
2. Feature extraction using TF-IDF
3. Train-test split (80:20)
4. Model training using Naive Bayes
5. Evaluation using accuracy score

## Results
- Accuracy achieved: 1.0
- Model successfully classified test data

## Conclusion
The project demonstrates that machine learning techniques can effectively
classify fake news using textual data.
